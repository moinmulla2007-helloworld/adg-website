Drop member photos in this folder.

File name = the person's full name, lowercase, words joined with hyphens.
Accepted formats: .jpg .jpeg .png .webp   (square crop, ~400x400px is plenty)

Examples:
  jitesh-zope.jpg
  angel-xavier.png
  dr-joanne-gomes.jpg      ("Dr." counts as a word; the dot is dropped)

Anyone without a photo automatically shows their initials instead.
